# RepoMind Web — Roadmap

- [ ] FastAPI wrapper (`api_server.py`) around existing RepoMind Python code, no logic changes
- [ ] Built-in sample data snapshot (RagCraft sample repo) for instant preview
- [ ] Web shell: sidebar nav, loaded repo status, server connection setting
- [ ] Dashboard: ingest repo (URL / sample), progress, metrics, entity & relation breakdowns
- [ ] Repository Explorer: upgraded interactive graph (type filter, motion presets, spacing), entity inspector, hubs, packages, file browser
- [ ] Chat: hybrid/graph modes, top-k, depth, suggestions, citations, graph paths, clear history
- [ ] What-If: quick scenarios, depth, risk banner, report, impacted subgraph, inventory, paths, citations, MD/JSON export
- [ ] Evaluation: controls, KPIs, 4 charts, verdict + matrix, results table + CSV, deep dive, glossary
